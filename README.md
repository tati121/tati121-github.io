TATI — Artist Website

- index.html — the complete website
- tati-photo.jpeg — the supplied artist photo

To use it:
1. Keep index.html and tati-photo.jpeg in the same folder.
2. Open index.html in a browser, or upload both files to a web host.

The site includes:
- Dark red/black aesthetic
- TATI hero section with the supplied photo
- About section
- Music placeholder
- Email contact button
- Instagram button
- Responsive mobile layout
- Star Static Records branding
